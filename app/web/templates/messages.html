Como funciona: Mensagens

Aqui você define tudo o que o bot escreve para os assinantes.

  • Palavras de entrada: quando o assinante manda uma delas (ex.: "oi", "bom dia"), o bot responde com as boas-vindas e os planos, igual ao /start.
  • Mensagens personalizadas: você cria respostas próprias. Defina as palavras-gatilho e o texto; quando o assinante mandar uma delas, o bot responde com o texto. Exemplos: "pix", "suporte", "como funciona". Elas têm prioridade sobre as palavras de entrada.
  • Mensagens do sistema: são enviadas automaticamente em cada etapa (boas-vindas, cobrança, pagamento aprovado, lembrete de vencimento...). Edite o texto à vontade; elas não podem ser excluídas, mas "Restaurar padrão" volta ao texto original.
  • Marcadores como {nome} e {vencimento} são trocados pelos dados do assinante. Cada mensagem mostra os marcadores que aceita.
  • Formatação: use <b>negrito</b>, <i>itálico</i> e <code>código</code>. Uma tag sem fechar faz o Telegram recusar a mensagem: use "Enviar teste" antes.
  • Enviar teste manda a mensagem para os admins cadastrados em Configurações (eles precisam ter dado /start no bot).

Use os marcadores entre chaves para inserir dados do assinante. A formatação aceita HTML do Telegram: <b>negrito</b>, <i>itálico</i>, <code>código</code>.

Lembretes de vencimento são enviados nos dias configurados em Configurações (atual: {{ reminder_days }} dia(s) antes). Assinantes com recorrência ativa no cartão não recebem lembretes.

Palavras de entrada

Quando o assinante mandar uma destas palavras ou frases, o bot responde com a mensagem de Boas-vindas e o menu de planos, igual ao /start. Coloque uma por linha.

Maiúsculas, acentos, pontuação e letras repetidas são ignorados, e vale também quando a mensagem começa com a palavra: oi reconhece "Oi", "oiii", "Oi, tudo bem?"; bom dia reconhece "Bom dia!!".

Mensagens personalizadas

Respostas que você cria: quando o assinante mandar uma das palavras-gatilho, o bot responde com o texto. Marcadores: {nome} {saudacao} {suporte}
