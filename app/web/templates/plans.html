Como funciona: Planos

Os planos são as opções que o assinante vê no bot ao mandar /start, /planos ou uma palavra de entrada (como "oi").

  • Pagamento único: o assinante paga uma vez (Pix ou cartão) e ganha os dias do plano. Se ainda estiver ativo, os dias são somados ao vencimento atual.
  • Recorrente: o cartão é cobrado automaticamente todo mês pelo Mercado Pago (sempre 30 dias). Só aparece se o cartão estiver ativado em Configurações.
  • PayPal: preencha o valor na moeda de Configurações (hoje {{ paypal_currency }}) para o plano aceitar PayPal. Em branco, o plano não oferece PayPal. Não há conversão automática: você define o preço. Planos recorrentes não aceitam PayPal.
  • Ativo: desmarcado, o plano some do bot, mas quem já assinou continua com o acesso.
  • Ordem: número menor aparece primeiro na lista do bot.
  • Novo plano: use o formulário no fim da página. O tipo (único ou recorrente) não pode ser trocado depois.
  • Excluir: só é possível se o plano nunca foi usado. Plano com membros ou pagamentos deve ser desativado.
  • Mudar o valor vale para as próximas cobranças. Assinaturas recorrentes já autorizadas mantêm o valor antigo.
