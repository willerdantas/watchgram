Como funciona: Plataforma

Configura quanto e como os usuários pagam para manter o bot funcionando.

  • Mercado Pago da plataforma: o access token da conta que recebe os pagamentos dos usuários. Cadastre o webhook para confirmação instantânea.
  • Teste grátis: quantos dias um usuário novo ganha ao ser criado.
  • Lembretes: em quantos dias antes do vencimento o usuário é avisado (por e-mail e pelo bot dele).
  • E-mail (SMTP): servidor que envia os lembretes. Salve e use "Enviar teste" para conferir.
  • Planos: nome, valor e duração de cada plano; desmarque "ativo" para escondê-lo.
  • Você (superadmin) e os usuários isentos não pagam.
